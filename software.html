INSEKT experiment interface

Student research assistant · ACTRIS / INSEKT · KIT

I contribute to INSEKT_pyGUI, the Python graphical interface used to operate KIT's INSEKT freezing-array instrument. My role involves extending and stabilising an existing application and improving it in response to laboratory use.

The interface supports the experimental workflow, from hardware connections and experiment setup to monitoring measurements and recording results. The application is used during live laboratory experiments.

My contribution

  • Continuing development of an inherited Python application.
  • Improving stability and usability for laboratory operators.
  • Resolving problems and refining features based on experimental use.
  • Supporting the workflow from experiment setup through measurement and output.

INSEKT_pyGUI is a collaborative codebase. My work builds on contributions from the original developers and the wider laboratory team.

Connecting software with the experiment

The application brings camera imaging, temperature measurements, and cooling control into a common interface. Supporting this environment requires attention to hardware communication, experiment state, and dependable data recording.

I also investigate compatibility between experimental outputs and downstream analysis workflows. This includes examining data structures and addressing differences between Python-based and established processing paths.
